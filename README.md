# Aesthetics 1.21.4 (Fabric)

Budowanie:
1. Zainstaluj JDK 21.
2. Z katalogu głównego projektu uruchom: `gradle build` (lub `./gradlew build`, jeśli wygenerujesz wrapper przez `gradle wrapper`).
3. Gotowy jar znajdziesz w `build/libs/aesthetics-1.0.0.jar`.
4. Wrzuć go do `mods/` razem z Fabric API 0.119.2+1.21.4 i Fabric Loader.

Klawisz domyślny: V (menu wyglądu).
